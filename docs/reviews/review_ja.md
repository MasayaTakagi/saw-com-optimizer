# 計画書レビュー

結論: 段階的に試作する計画として妥当。ただし、以下を明記して条件付きで採用する。

1. **比較する量**: 実抵抗終端での transducer gain は、その抵抗に電力正規化した |S21|² と一致する。「基準を変えたS21は常に不適切」ではなく、各抵抗を実際の終端条件として使い、利用可能電力を統一する点が本質。本実装は電圧・電流から直接求め、S行列と独立に照合する。
2. **帯域外の精度**: 同期周波数近傍の単一モード・一定COM定数を10～1000 MHzへ外挿する。低域減衰を計算できても定量的な裏付けはない。FEM/測定による校正前に実用的な最適抵抗を判断しない。
3. **結線の確定**: 図の3-IDTは典型的なDMSの全結線を一意に定めない。本試作は左右IDTを別の外部ポート、中央IDTを接地または無電流の浮遊ポートとする。浮遊とはバスバー間の差動電圧を未知数にした単一電気ポート。基板に対する共通モードの浮遊は含まない。
4. **位相と寸法**: IDTは一対一波長、反射器は一電極半波長。IDT・反射器ブロック端でCOM包絡線の位相を再設定する規約。ギャップは物理伝搬位相。電極の端部極性、半波長の移動とバスバー極性の対応は実レイアウト照合が必要。整数の反射器本数を扱うが位相原点も含めた実デバイス再現性は未検証。
5. **目的関数**: 有限のペナルティ重みは辞書式の制約優先を保証しない。最適化はペナルティ、保存済みシード・抵抗間の順位は仕様達成→最大正規化違反→目的関数とする。
6. **製造制約**: 指幅は λ×メタライゼーション比/2、間隔は λ×(1−比)/2。長さ・電極総数の不適合候補はCOM計算前に拒否。パッケージ内のパッド・配線面積は未設計。

## 試作の範囲

COM、回路評価、7変数探索、3シード、11抵抗点、上位近傍追加探索、密な再評価、CSV/HTML、シード単位の再開を実装する。規約の解析極限と行列指数で検証し、測定波形との照合は未実施。

計画書全項目の完成版ではない。並列ワーカー、DE集団・乱数状態を含む厳密な途中再開、寸法依存材料補間、寄生回路、Touchstone、局所探索は未実装。中断したシードは同じ初期状態から再実行し、完了シードを再利用する。標準探索予算は各シード最大70評価程度。30,000評価や十分な収束を主張しない。最終グリッドは5001点の全域基底に各評価帯域の密グリッドと2段階の適応細分化を追加するが、任意に狭い共振を必ず捕捉する保証はない。

COMの検証資料: [The Extraction of Coupling-of-Modes Parameters in a Layered Piezoelectric Substrate and Its Application to a Double-Mode SAW Filter](https://pmc.ncbi.nlm.nih.gov/articles/PMC10745400/) のP行列式(4)。本試作ではまず無反射IDTの同期極限・無励振反射器の極限を照合する。商用B28フィルタの性能・材料定数を再現したものではない。
