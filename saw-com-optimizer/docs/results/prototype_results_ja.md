# 実行結果

使用モデルはhypothetical。材料・実測の校正は未実施。

- 基準応答、50 Ω単独探索、11抵抗×3シードの探索を完了。
- 追加探索は35、45 Ω。再開不具合の確認時に55 Ωも実行したため、その結果も捨てずにレポートへ含めた。合計14抵抗×3シード。
- 最終探索は各シード14個体、20世代。キャッシュ・製造制約事前拒否により実際のCOM評価数は条件によって異なる。
- 暫定上位は45 Ω。最悪帯域内損失10.6614 dB、リップル5.4704 dB、入力/出力VSWR約5.7403。全条件で仕様未達。
- この順位は採用した仮モデル、探索範囲、探索予算内での結果。実製品の最適抵抗や大域最適性を示さない。近隣抵抗からの初期候補共有があるため、シード幅ゼロも収束の証明にならない。
- 回路解析、COM極限解、行列指数・分割照合、受動性、相反性、浮遊端処理、再現性、シード単位再開を7テストで確認。
- 再開で細分化の中心が移動するCLI不具合を修正。既存数値は変わらないため保存し、manifestに修正前コードハッシュと移行理由を記録。修正後の同一コマンドは約3.4秒で完了し、既存結果を再利用した。

表示: `runs/refined-prototype/report.html`。全数値: 同フォルダ `comparison.csv`、シードごとのJSON/NPZと履歴JSONL。
