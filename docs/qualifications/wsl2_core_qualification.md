# WSL2 core qualification — archived and retired

> **ARCHIVAL / NON-OPERATIONAL.** The former Codex/Stage 4B/Stage 4C WSL
> qualification workflow is retired. Its executable bootstrap, qualification,
> smoke, and report-collection scripts were removed under Issue #118; there is
> no current command path to run or resume this qualification. Do not recreate
> those scripts or treat this historical plan as execution authorization.

The [original pre-retirement plan and environment inventory](../history/wsl2_core_qualification_original_archival_20261024.md)
is preserved verbatim as historical context. Its commands are not supported or
authorized for execution.

This page records a superseded environment/qualification proposal. It is not a
current setup guide, a report of a newly completed qualification, or permission
to run Codex, COM/FE, an optimizer, checkpoint recovery, or a scientific study.
The prior script workflow mixed host setup with Stage 4A evaluation, Stage 4B
matched-cell optimization/checkpoint work, and Codex-specific checks; removing
that workflow did not alter the independent current COM/evaluation,
optimization, checkpoint, or WSL host-safety implementations.

Previously recorded review reports and scientific evidence remain unchanged.
Their contents and historical source identities are not regenerated or
reinterpreted by Issue #118. The remaining WSL host diagnostics/install tools
(`preflight.ps1`, `install-wsl.ps1`, `diagnostic-helpers.ps1`, and
`test-diagnostics.ps1`) are separate host-facing tools and are not authorized
for execution by this archival page.

For current development setup and locked-environment commands, see the
[development environment guide](../guides/development_environment.md). For
scientific and production run authorization, see the
[experiments policy](../experiments.md). Issue #118's source, caller, test,
and preservation record is in the
[Stage 4C execution retirement plan](../plans/issue118_r6c2b3a_stage4c_execution_retirement_20261024.md).
