# 50 Ω固定探索の結果

Rs=Rl=50 Ω。仮COM定数による構成・寸法探索。57試行、33,189候補評価、計算時間合計約833秒。7,914候補は寸法・配置制約違反で事前拒否され、数値計算失敗や受動性違反は評価履歴に記録されていない。

| 比較対象 | 最悪通過帯域損失 |
|---|---:|
| 従来結線のDMS単独 | 10.90 dB |
| 中央入力・左右同相出力のDMS単独（追加探索後） | 8.54 dB |
| 上記DMS＋入力側並列共振子1個 | 6.55 dB |
| 上記DMS＋入出力側並列共振子各1個 | 6.50 dB |

各値はその構成内で仕様違反順位により選択した候補。構成による改善効果と有限予算の探索差は完全には分離できていない。全構成で仕様未達。

## 暫定上位：P_D_P

入出力の信号ノードからそれぞれ1ポートSAW共振子を接地する。中央IDTを入力に接続し、左右IDTを同相で出力へ並列接続するDMSを中央に置く。

| 指標 | 結果 | 目標 |
|---|---:|---:|
| 最悪挿入損失 | 6.50 dB | ≤3.0 dB |
| リップル | 3.05 dB | ≤2.0 dB |
| 入力VSWR | 4.54 | ≤2.5 |
| 出力VSWR | 3.98 | ≤2.5 |
| 10–700 MHz最小減衰 | 36.34 dB | ≥20 dB |
| 703–748 MHz最小減衰 | 31.83 dB | ≥32 dB |
| 832–862 MHz最小減衰 | 16.00 dB | ≥30 dB |
| 880–915 MHz最小減衰 | 28.42 dB | ≥30 dB |

推定配置外形623×440 µm、総電極数488本。DMS波長5.00886 µm、左右20対・中央17対、左右反射器各48本、開口66.41 µm。入力並列共振子は波長5.28193 µm・35対・開口65.18 µm。出力並列共振子は波長5.29726 µm・24対・開口128.06 µm。追加共振子の反射器は各側40本固定。

最悪損失点765.74 MHzでは、利用可能電力の約25.6%が入力反射、22.4%が負荷へ伝達、52.0%がモデル内の散逸・音響放射に相当する。整合改善だけで損失を解決できるとは限らない。電圧電流から計算したGTと|S21|²の差はこの候補で約6.1e-16。

## 検証・再現

物理モデル・回路合成・再現性・再開に関する12テストを実行し合格。全57試行完了後の再実行で試行ファイル変更0件を確認。周波数図と追加共振子単体図を目視確認した。

探索中にレポートの保存関数importと表示を修正した。数値計算・最適化・選択条件に変更はなく、manifestに探索開始時のソースハッシュと変更理由を保存。source_snapshotに初期コードを保持した。

## 次に調べること

1. 832–862 MHzの減衰不足と通過帯域損失が主要課題。直列共振子を含む構成は一次比較で劣ったが、探索不足を理由に完全には除外しない。
2. 現在40本固定の追加共振子の反射器本数・間隔を変数化し、閉じ込め・損失の影響を検証する。総電極上限500に近いため、素子間の電極配分も同時に見直す。
3. 同一50 Ωのまま上位構成を継続探索し、校正済みCOM定数・寄生回路を導入して順位の安定性を確認する。

結果は `runs/hybrid-50ohm/report.html`、`comparison.csv`、`all_trials.csv`、`power_budget.json` と各試行JSON/NPZに保存。実測・FEM校正前のため実デバイス性能や最適構成を保証しない。
