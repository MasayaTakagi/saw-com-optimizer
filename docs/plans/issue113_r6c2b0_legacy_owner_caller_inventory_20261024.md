The classification terms below are recommendations for future decisions, not permission to execute or delete:

- **KEEP** — observed active software, safety, regression, scientific, or evidence owner; retain its present contract.
- **DELETE_CANDIDATE** — specific code or route is statically unreachable/retired; removal still needs a scoped source work order and negative tests.
- **DEFER** — callers, future support, or historical use are unresolved; preserve pending a focused disposition.
- **STOP_FOR_OWNER** — removal or behavior change would affect scientific meaning, an executable study, external/run safety, or an explicit owner boundary.
- **UNKNOWN** — repository-only inspection cannot establish external scripts/configs/imports, current processes, or other-host state.

Static searches identify tracked callers, not every invocation. No active process, active-run registry, external run root, raw/checkpoint/log/session payload, credential, or user-level configuration was inspected. ### Explicit safety consequences / unknowns

- `worktree_safety`'s repeated audit and registry lock are not a universal filesystem transaction. Any deletion/removal scope must preserve existing race handling and document the non-cooperating-writer limit.
- `validate_persistent_run_location` plus a later reservation/active-run registration is a multi-step boundary. Do not simplify validation, registration, or exclusive creation independently.
- Worker terminal failure, full traceback, failing cell/stage, child exit state, last durable checkpoint, and completion disposition prevent a failed/incomplete process from being presented as completed. Do not collapse errors into a success-looking state.
- `format_status` is per-run status rendering, not a global active-run inventory. `recover`, `launch --resume`, publication, administrative closeout, and worktree removal may mutate state; none is authorized here.
- No active-run metadata scan is included. Under current #75 policy, any destructive runtime cutover that depends on whether a legacy run is active requires its own authorized bounded metadata-only inventory. Here that status remains **UNKNOWN / STOP**.
